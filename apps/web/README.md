# Landing (`web`)

Next.js site for [pd-portfolio-review](https://github.com/leonardobetti/pd-portfolio-review).

From the monorepo root:

```sh
bun install
bun run dev
```

Vercel: set the project **Root Directory** to `apps/web` (include files outside the root so the root `bun.lock` is available). Planned domain: `pd-portfolio-review.vercel.app`.
